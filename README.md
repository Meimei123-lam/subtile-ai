# 🎬 AI Video Subtitle Cleaner, Translator & Replacer

Bộ công cụ tự động nhận diện vị trí phụ đề cũ trên video, dịch thuật sang tiếng Việt, xóa chữ gốc bằng AI Generative Inpainting (LaMa) và chèn lại phụ đề mới đúng tọa độ.

## 🚀 Chạy nhanh trên Google Chrome (Không cần cài đặt)
Mở file `run_colab.ipynb` hoặc chạy trực tiếp trên [Google Colab](https://colab.research.google.com/) với GPU T4 miễn phí.

## 💻 Cài đặt chạy cục bộ (Local)
1. Cài đặt thư viện:
   pip install -r requirements.txt
2. Khởi chạy giao diện:
   streamlit run app.py
